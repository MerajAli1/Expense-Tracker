## 🚀 Quick Start

Open PowerShell:
```powershell
cd d:\Expense_Tracker\backend
$env:JAVA_HOME = "C:\Program Files\Java\jdk-21"
.\mvnw.cmd spring-boot:run
```

- Server URL: **`http://localhost:8081`**
- Test Endpoint: **`http://localhost:8081/api/expenses`**
